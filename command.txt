Commands:
  d <ext|sip-uri>  : dial (video enabled)
  a                : answer incoming (200 OK, with video)
  h                : hangup active call
  w <path.wav>     : play WAV into call
  tx <gain>        : set TX level (e.g. 1.10)
  rx <gain>        : set RX level (e.g. 1.05)
  pv [cap_id]      : start local camera preview (default cap 0)
  pvoff [cap_id]   : stop local camera preview (default cap 0)
  lsvid            : list video devices (cap/render)
  q                : quit
